# Coordinator timeline archive

One picture per completed day (Europe/Helsinki calendar day), named `YYYY-MM-DD-coordinator-timeline.png`. The picture is exported from the interactive timeline's data (`docs/progress/timeline/events.json`) after the day ends. It is never posted during the day and a partial day is never filed as final.

The interactive timeline is the live view: https://files.instinct.com/9ikwv5puwqvj-coordinator-work-timeline

Earlier days stay here and in the event data. They are not overwritten. A mistaken past event is corrected by a later entry that supersedes it, with the original kept in git history.
