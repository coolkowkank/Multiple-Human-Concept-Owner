## Proposed run shape (matches the tighter prior authorized envelope)

- Disposable fresh lane; new seed brief for a tiny library + tests (WP4's named
  task class; not a replay of the e51fae66 prompt).
- Seats: coordinator, builder, reviewer, qc as http seats; records stays a
  scripted queue seat (deterministic archiving, no judgment - labeled as such,
  never described as a model).
- Models (author-chosen mapping, subject to review; model quality for these
  seats is unproven): builder, reviewer and qc on
  nvidia/nemotron-3-ultra-550b-a55b; coordinator on novita/ling-3.1-flash;
  novita/inclusionai/ling-3.0-tiny unused.
- Caps: call_budget 6 per seat, max_tokens 4096 (the e51fae66 authorized
  values, tighter than the fence maxima).
- Reviewer pin: the reviewer seat's instructions require its verdict file to
  name the exact 40-hex head it reviewed - this closes the "Reviewer verdict
  names no pin" gap the independent reviewer found in the scripted demo. QC
  verdict names its head as before.
- Prompts derive only from the repo's own brief/seed files. No private bundle,
  ledger, grant, key or checker content in any prompt, ever.

## Evidence and acceptance mapping (checked on real run evidence, after the run)

1. Unattended: zero operator intervention/gate rows; guarded close.
2. Seat sequence includes a real reviewer turn (reviewer-skip guard active).
3. Reviewer verdict file names the reviewed head.
4. QC verdict head and final HEAD have byte-identical src/ and tests/ (same
   application pin).
5. No manual recovery; no restart/error rows.
6. Usage logs reconcile to <=6 calls per seat, price-0 models only.
A sanitized result document (no raw model text) plus the lane's commits go to
the independent reviewer through main. No WP4 credit is claimed by this plan or
by a lone author run; credit requires independent review of the real evidence.

## Failure honesty

outcome is reported as-is; failed or unknown outcomes stay consumed - no retry,
reset or envelope change without fresh authorization through main.
