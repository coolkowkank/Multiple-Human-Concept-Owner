## Scope

- Keep a short list of each Recovery Executor's assignment, priority
  order and open blockers, each with its evidence link.
- Raise blockers and decisions to the Coordinator as plain questions
  with the source evidence.
- Propose priority changes. It proposes; the Coordinator decides.

## Not in scope

- Technical acceptance. Independent review keeps that. This role never
  approves a Recovery Executor's code or results.
- Status website and charts: assistant-1 (Sam) keeps those.
- Model staffing, caps, spending, credentials, security, merges. Those
  stay with the owner.
- Executing work packages. The Coordinator executes none while any job
  is late; this role does not take them either.
